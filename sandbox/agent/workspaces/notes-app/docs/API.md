# HTTP API

Усі відповіді — JSON. Помилки: `{"error": "<код>", "detail": "<текст>"}`.

| Метод і шлях | Що робить | Коди |
|---|---|---|
| `POST /notes` | створити нотатку `{title, body, tags?}` | 201, 422 (ліміти) |
| `GET /notes/{id}` | нотатка за id | 200, 404 (немає або видалена) |
| `PATCH /notes/{id}` | змінити поля | 200, 404, 422 |
| `DELETE /notes/{id}` | мʼяке видалення | 204, 404 |
| `POST /notes/{id}/restore` | відновити видалену (до 30 днів) | 200, 404, 410 (минуло 30 днів) |
| `GET /search?q=...&tag=...&limit=20` | пошук | 200, 422 (порожній запит) |

## Пошук

`q` розбивається на слова (від 2 символів). Нотатка підходить, якщо містить **усі** слова в заголовку або
тексті. Ранг: збіг у заголовку важить 3, у тексті — 1; за рівного рангу новіші — вище. `limit` — до 100.

## Коди помилок

- `title_too_long`, `body_too_long`, `too_many_tags`, `bad_tag` — 422;
- `not_found` — 404;
- `retention_expired` — 410.
