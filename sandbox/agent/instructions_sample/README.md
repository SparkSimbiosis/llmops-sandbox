# Синтетичний приклад реєстру інструкцій

Вигадані ролі, правила, workflow, контракти й skills для стенда й тестів. Структура каталогу — та сама, що
очікує імпорт (`sandbox/agent/instructions.py`): `agents/*.md` — ролі, `policy/*.md` — правила,
`workflows/*.md`, `contracts/*.md`, `skills/<name>/SKILL.md`. Цей README не імпортується.
