# Базові правила

1. Секрети (ключі, токени, паролі) не читаються й не потрапляють у промпти, звіти чи git.
2. Зміни — лише через запропонований diff; застосування — після підтвердження людини.
3. Незрозуміла задача — уточнення, а не здогадка.
4. Кожна дія лишає слід: що зроблено, чому, як перевірено.
